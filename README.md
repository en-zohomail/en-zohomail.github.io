# Zoho Mail Helpdesk — Blue/Teal GitHub Pages Website

This project adapts the supplied Roadrunner reference ZIP's visual theme for Zoho Mail.

## Included
- `index.html` — homepage
- `blog.html` — searchable library of all 100 guides
- `support.html` — separate support resources page
- `articles/` — 100 individual full-length article pages
- `styles.css` — shared blue/teal responsive theme
- `config.js` — editable site, navigation, navbar button and article configuration

## GitHub Pages deployment
1. Extract the ZIP.
2. Upload the contents to the root of your GitHub repository.
3. In repository Settings → Pages, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then save.

## Customization
Edit `config.js` to update article titles, descriptions, categories, SEO metadata and article content. The HTML pages are static copies for direct GitHub Pages loading; when editing article content in `config.js`, also update the matching article HTML file to publish the change. Update menu labels in the shared navigation markup in the HTML pages.

## Buttons and links
Login and Support are non-linked buttons in the navbar. No external links or third-party chat widget are included. Internal navigation links between the homepage, blog, support page and article pages are retained.
